# SRS.md — دار القرآن (تفسير ذكي + تلاوات)

## Functional Requirements
- FR1: 114 سورة + بحث فوري (مصدر النص/الترجمة: Quran.com API — مؤكَّد).
- FR2: عارض آية + تفسير من 3 مصادر معًا: الطبري، ابن كثير، السعدي (مؤكَّد — تبويب/اختيار بينها).
- FR3: تبديل عرض/إخفاء الترجمة الإنجليزية.
- FR4: تلاوات صوتية (Streaming) — مصدر مجاني وموثوق الترخيص (NEEDS RESEARCH لتحديد المصدر بدقة).
- FR5: RTL + تصميم فاخر (ذهبي + كحلي داكن — مؤكَّد).
- FR6: إعلانات بمسافة بصرية واضحة عن النص القرآني (لا تجاور مباشر).

## Non-Functional Requirements
- دقة دينية حرجة: نص القرآن/الترجمة من Quran.com API فقط، لا توليد AI حر للنص. التفسير: AI يصوغ/يلخص من الكتب الثلاثة المعتمدة + مراجعة بشرية إلزامية دقيقة قبل النشر.
- Licensing: تلاوات القراء تحتاج تحقق ترخيص قبل الاستضافة (NEEDS RESEARCH إلزامي).
- Performance: Lazy Loading صارم للصوت، Lighthouse > 90 رغم الحركات البصرية.

## User Stories
US1: كمستخدم يقرأ آية، أريد تفسيرًا فوريًا من مصدر موثوق، حتى أفهم المعنى.
AC: عرض 3 تفاسير (الطبري/ابن كثير/السعدي) قابلة للتبديل، منسوبة لمصدرها، خلال أقل من ثانية (محتوى ثابت).
US2: كمستخدم، أريد تشغيل تلاوة، حتى أستمع أثناء التصفح. AC: Streaming لا تحميل كامل، لا Autoplay.
